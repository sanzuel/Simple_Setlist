# SongSetlist

Android-ready SongSetlist project for Codemagic.

Features included in this starter build:
- Library search
- Song name + whole-number BPM
- Song 3-dot menu
- Add to Setlist
- Setlists with song counts
- Add new setlist
- Dark UI with subtle neon-green accents
- Codemagic release workflow

Before production release, configure the Android keystore in Codemagic and replace the sample data with the final project data/behavior.
